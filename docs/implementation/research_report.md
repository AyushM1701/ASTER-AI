# Aster recovery study: measured development results

## Abstract

This execution adapted an existing local dental education application under the owner-adopted master implementation prompt. Generic question-planning defects were repaired, request-scoped diagnostic observations were added, and exact prepared-unit bindings were inspected. Forty previously unbound units and their parents were read;31 units received44 bindings while9 remained unbound. Three licensed, narrowly inspected review paragraphs and one bounded paired explanation were added to an inactive candidate. In a visible107-case/111-turn development bank, substantive turns increased from16 to18; substantive complete turns increased from3 to4. The pre-paper regression checkpoint passed1,078 tests; the latest private-paper checkpoint passed1,098 tests. Independent medical accuracy, unseen performance and trained-model efficacy are unestablished.

## Introduction

The measured problem is low evidence-supported educational completion across nine MDS specialties. A functioning HTTP service, many indexed documents and resolved citations are insufficient. The original source-bound pipeline remains default; no architecture/index/model migration or active knowledge promotion occurred.

## Related work

This is a preliminary primary-source review, not an exhaustive current novelty assessment. These precedents motivate controlled comparisons; adding a facet gate does not establish neural novelty or clinical probability calibration.

## Method

Question planning now preserves adjectival coordinated nouns, treats examples as facets, accepts operation lists preceding a subject and uses explicit case findings instead of fictional_case as a disease topic. Unknown case subjects request clarification. Diagnostics use trusted vocabulary or opaque request-scoped names; independent triage and browser visibility remain null. Candidate count is an observed retrieval quantity, not proof of source availability.

The offline research code includes rights/holdout manifests, split overlap checks, a four-arm oracle framework, metric calculations and an untrained compact FGRC reference network with328,680 trainable parameters. It implements pair relevance/relation heads, case answerability/acceptance, source-group aggregation and masked candidate objectives. Padding/ineligible candidates cannot alter conflict aggregation. These are mechanics-tested components, not a trained or calibrated B7 system. A controlled retrieval/guard harness and local blinded assignment/import/adjudication workflow were added. B2/B3/B5 are retrieval components rather than complete generated baselines. Full B0–B8/E1–E15 labelled comparisons remain unfinished.

## Limitations and ethics

## Conclusion

The observed outcome is a small development coverage gain with preserved evidence restrictions. Full master implementation and all-MDS educational coverage remain unfinished. Complete, applicable foundational sources and independently labelled references remain the next coverage and research prerequisites.
