# Intended use

Aster explains a limited approved reference library, transcribes a single image
for explicit human confirmation, and implements experimental selected chest
research outputs from a separate cached classifier. English initially. The
local prototype uses synthetic documents and permitted de-identified images.

No autonomous diagnosis, medication selection, individual dose calculation,
treatment changes, or assurance of radiographic normality. General reference
text is not a personal recommendation. OCR can be wrong; confirmation attests
to entered text rather than medical appropriateness. Unsupported, unresolved,
unavailable or unregistered inputs abstain explicitly. This scope is displayed
in the interface, README, and exported response limitations.
