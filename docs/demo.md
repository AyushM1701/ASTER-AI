# Local demonstration

1. Launch the services; show local status and intended use.
2. Ask “What is asthma?”; expand its reference and inspect the primary URL.
3. With general chat enabled, ask an uncovered question; show the pretrained
   model response and its explicit lack of verified local citations. Extractive
   mode still abstains outside the small corpus.
4. Enter a synthetic urgent fixture; guidance does not depend on Ollama.
5. Open the link icon beside the message box and attach the synthetic document.
   The model routes it to prescription review and real OCR; duration stays blank.
6. Compare the OCR fields with the original. The API blocks unconfirmed explanations.
7. Select Confirm and explain; a source-linked metformin overview appears in chat.
8. Edit a field; confirmation and any old explanation are invalidated.
9. Show the imaging setup state and arbitrary-asset rejection. Actual research
   scoring can only be demonstrated after permitted asset and model setup.
10. Clear the session; old IDs/token cannot be reused. Restart services to show
    intentional loss of process-local state.
