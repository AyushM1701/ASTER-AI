## Evaluation limitations

- This is an independent automated source/software review, not a faculty or clinical accuracy assessment. All89 MDS and93 MBBS stored questions/citation sets were inspected for topic fit; only listed factual concerns received independent counterevidence checks. Every sentence has not been clinically validated.
- The89 photographed-topic probes each ask only Explain+title; compound named facets can be absent even when status is ok. No per-facet answer requirement or complete-answer criterion existed in this run.
- The93 MBBS benchmark comprises27 bounded topics with3 variants plus12 boundary cases, not all2626 active extracted MBBS competencies. Some official subjects have no supported benchmark case.
- Required-fact phrase lists and expected source IDs are derived from the same local reference paragraphs and developer-authored notes used by the runtime; agreement is not an independent examination.
- Claim support is exact source text or equality with a validated developer unit. It verifies copying/binding, not truth, relevance, omission, contradiction outside listed forbidden phrases, or evidence strength.
- Claim-support denominator79 excludes2 unanswered supported cases; 100% on that metric does not mean all81 supported requests were answered.
- Retrieval source hit can pass using an unused candidate rather than an emitted citation. Source identity does not establish requested subtopic evidence.
- MCQ examples contain extremely obvious two-option choices and their target words; matching facts cannot establish actual answer choice reasoning, distractor robustness or examination competence.
- Boundary cases evaluate TeachingStore non-handling, not the AnswerService/API urgent and professional-review routes.
- Practical skills, specimen handling, slide identification, staining performance, microscopy operation, OSPE/OSCE, research performance, thesis appraisal and patient communication require separate labelled assets or human assessment.
- Absent figures/tables/code outputs produce dangling references and missing workflow detail in extracted prose; formulas elsewhere do not repair every isolated chunk.
- No full clinical, oral pathology diagnostic, dosing, handwriting or calibrated X-ray accuracy follows from these artifacts. New fixes require a fresh pinned release evaluation; this report audits preserved pre-fix outputs.

- OCR document fields require every current field and a revision-bound user confirmation before explanation. Transcription confirmation is not clinical approval; unreadable fields remain blank. No labelled handwriting validation was performed by this audit.
- X-ray research inference requires registered hash-checked adult frontal assets and permitted weights; arbitrary image uploads cannot be scored. Outputs state integration-only, uncalibrated scores and no normality verdict. No external clinical validation was performed by this audit.
- Existing sourceholds78 and legacy medical/OCR/X-ray limitations must survive every new release. Findings here propose additional bounded holds, never removal of old holds.
